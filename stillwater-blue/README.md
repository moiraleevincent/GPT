# Stillwater Blue — A4 lighting study

**Original:** [A1 / Stillwater](../stillwater/index.html)  
**New study:** [A4 / Stillwater Blue](./index.html)

A separate copy of A1, preserving its creatures, timing, gestures, plant placements, stones, interactions, and camera motion. This first experiment deliberately changes only the environmental color and lighting.

## Changes in A4
- Deep ocean gradient shifts from green-teal toward **cobalt blue**, retaining darker depths.
- Six geometric light wedges are replaced by **two broad, feathered shafts** and a diffuse surface wash.
- Horizontal shimmer is confined to the upper water instead of repeating all the way down the glass.
- Depth haze, edge shading, and top reflection are cooled toward blue.
